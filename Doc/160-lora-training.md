# LoRA训练

`LoRA训练`与 `模型训练`的交互方式相同：编辑参数 → 生成 TOML → （可选）启动 PowerShell 训练脚本。区别在于默认输出配置与默认参数分组更贴近 LoRA 的常见写法。

## 快速上手

1. 选择 `lora-scripts 目录`。
2. 设置 `TOML 输出路径`（默认指向 `config/lora.toml`）。
3. 选择/填写 `训练脚本路径`（默认 `train_by_toml.ps1`）。
4. 在参数分组中按需修改（数据集、网络维度、优化器、训练轮数等）。
5. 点击“仅生成 TOML”或“生成并开始训练”。

## 注意事项

- 执行逻辑与 `模型训练`一致：写 TOML → 打开新的 PowerShell 终端 →（可选）激活 `./venv` → 运行脚本。
- 参数写入规则同 `模型训练`（布尔/数值/字符串/Raw）。
