# Gemini图像生成

`Gemini图像生成`通过 Google Gemini API 进行带图生图：输入提示词 + 若干素材图片，返回一张生成结果，并自动保存到本地 `output/`。

## 使用前准备

- 需要可用的 Gemini API Key（可从环境变量 `GEMINI_API_KEY` 自动读取，也可在页面输入）。
- 需要网络访问 `https://generativelanguage.googleapis.com/`。

## 快速上手（单次生成）

1. 添加素材图片（支持拖拽到“素材图片”区域，或点击选择；最多 10 张）。
2. 选择模型、设置温度与输出尺寸（1K/2K/4K）及长宽比（可不选）。
3. 填写提示词。
4. 点击“开始生成”，任务会进入队列并自动执行。

## 批量生成

`批量生成`会把前 `批量张数` 张素材图按“每张图一个任务”加入队列，并在任务间随机等待：

- 等待范围：`批量等待(s)` 的最小/最大值（包含端点）
- 用于减少触发频率限制的风险

## 队列与限制

- 队列最大长度：50 个任务（超过会拒绝入队）。
- 单张素材图片大小上限：12MB（超过会跳过该图片）。
- 队列状态：页面会显示 `当前队列任务x/y`。

## 输出位置

- 生成结果会保存到程序基目录下的：`output/`
- 文件名规则：
  - 单张素材时会带素材名：`<素材名>-gemini-<时间戳>.png`
  - 多素材时：`gemini-result-<时间戳>.png`
- 点击结果图区域可打开最近一次输出目录。

## 配置保存/加载

页面支持保存配置到：

- `config/GeminiPic/<配置名>.json`

注意：配置文件会以明文保存 API Key（日志也会提示），共享环境下请谨慎使用。
