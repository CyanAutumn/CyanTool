# 分辨率筛选

`分辨率筛选`用于按分辨率条件批量删除图片（并删除同名 `.txt`）。它会递归遍历输入目录下的所有子文件夹。

## 适用场景

- 清理过小分辨率图片，避免低质量样本进入训练集。

## 快速上手

1. 在“图片文件夹路径”填写或粘贴要处理的目录。
2. 选择需要启用的筛选条件：
   - 高度阈值：删除高度小于指定值的图片
   - 宽度阈值：删除宽度小于指定值的图片
   - 总像素阈值：删除 `宽*高` 小于指定值的图片
3. 点击“开始筛选”。

## 删除规则（重要）

- 遍历范围：`输入路径`下所有子目录（会递归遍历）。
- 支持格式：`.png` / `.jpg` / `.jpeg` / `.bmp` / `.gif`
- 删除顺序：
  1. 若启用高度筛选且高度不足 → 删除
  2. 否则若启用宽度筛选且宽度不足 → 删除
  3. 否则若启用总像素筛选且像素不足 → 删除
- 删除图片时，会同时删除同名 `.txt`（例如 `a.jpg` 会尝试删除 `a.txt`）。

该操作不可逆，建议先备份再运行。
