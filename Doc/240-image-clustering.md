# 图片聚类

`图片聚类`会为图片提取向量特征（Style/Content），再用聚类算法分组，并把图片与同名 `.txt` 复制到输出目录的不同分组文件夹中。

## 使用前准备

- 需要模型文件：`Models/csd/csd_clip_model.onnx`
  - 若缺失会提示错误并停止。

## 快速上手

1. 选择“输入文件夹”（支持递归子目录）。
2. 选择“输出文件夹”（将创建分组子目录）。
3. 选择计算设备（CPU/GPU）、特征类型（Style/Content）、聚类算法。
4. 点击“开始聚类”。

## 参数说明

- 计算设备：
  - GPU：会尝试使用 ONNX Runtime CUDA Provider；失败会自动回退 CPU，并在日志中说明原因。
  - CPU：直接使用 CPU 推理。
- 特征类型：
  - Style：以风格向量聚类
  - Content：以内容向量聚类
- 聚类算法：
  - KMeans：需要设置“聚类数量 (K)”
  - HDBSCAN：需要设置“最小簇大小”

实现细节：

- 特征向量会先用 PCA 降到 2 维，再进行 KMeans/HDBSCAN。
- HDBSCAN 的噪声样本会被分到 `noise/`（clusterId 为 `-1`）。

## 输出结构

输出目录下会生成：

- `group_<id>/`：聚类分组（KMeans 的 id 从 1 开始）
- `noise/`：HDBSCAN 的噪声/离群点

每个分组内会复制：

- 图片文件
- 若存在同名 `.txt`，也会一并复制

## “移动子文件夹文件到最上层”

该按钮会把输入目录的所有子目录中的文件移动到输入目录顶层：

- 若顶层已存在同名文件，会跳过并记录日志
- 操作结束后会尝试删除**顶层的空子目录**（较深层级的空目录可能需要手动清理）

此操作会改动文件结构，建议先备份。
