# 训练集配平

`训练集配平`用于对训练集的子文件夹（通常按“重复次数_repeats_内容”命名）进行统计与配平，计算每个子文件夹建议的重复次数，并可一键重命名应用到目录结构中。

## 适用场景

当你的训练集按子文件夹组织，每个子文件夹图片数不同，希望通过 repeats 让各子集在训练步数占比上更均衡。

## 快速上手

1. 点击“选择文件夹”，选择一个包含多个子文件夹的父目录。
2. 查看表格中的“图片数量/重复次数/训练步数占比”。
3. 点击“一键配平”自动计算 repeats。
4. 确认无误后点击“应用”将重复次数写回到子文件夹名（重命名）。

## 计算规则

- 对每个子文件夹统计顶层图片数量（`.png/.jpg/.jpeg/.webp/.bmp`）。
- 以最大图片数为基准：
  - `Repetitions = round(maxImageCount / imageCount)`，最小为 1
- “训练步数占比”按 `imageCount * repetitions` 计算百分比。

## 应用（重命名）规则（重要）

点击“应用”后会直接重命名子文件夹：

- 若原文件夹名为 `5_foo`，会先去掉前缀 `5_`，得到 baseName `foo`
- 新名称为：`{Repetitions}_{baseName}`
- 若目标名称已存在，会报错并跳过该项

该操作不可逆，建议先备份再执行。
