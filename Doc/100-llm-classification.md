# LLM分类

`LLM分类`用于把一个文件夹中的图片交给本机 LLM（LM Studio 本地接口）逐张分析，并按模型返回的“等级”把图片（及同名 `.txt`）移动到不同目标文件夹。

## 适用场景

- 按“质量/符合度/风险/喜好”等维度，把图集自动分到 1~5 档文件夹。
- 用你自定义的提示词约束输出格式（要求模型返回 JSON）。

## 使用前准备

- 启动 LM Studio，并开启“OpenAI 兼容接口”（默认地址通常为 `http://127.0.0.1:1234`）。
- 选择一个支持图像输入的模型（或确保你使用的模型能正确处理“带图片的对话输入”）。

## 快速上手

1. 在“工作文件夹”选择待处理图片所在目录（只处理该目录顶层的图片）。
2. 设置“路径 1~5”为不同等级的目标目录（可留空，但不建议）。
3. 在“主输入”写提示词，要求模型输出 JSON，例如（示例仅供参考）：
   - 让模型输出 `{"level": 1..5, "reason": "..."}`，并明确只输出 JSON。
4. 点击“运行”开始处理。

## 处理规则说明

- 处理文件类型：`.jpg` / `.jpeg` / `.png` / `.webp`
- 对每张图片：
  - 调用 LM Studio 的本地接口，同时携带提示词与图片。
  - 解析模型返回 JSON 的 `level` 字段：
    - `level` 为 1~5 且对应目标路径已配置：移动到对应目录
    - 其它情况：移动到工作目录下的 `other/`
  - 若存在同名 `.txt`（例如训练标注），会与图片一起移动。
- 若接口请求失败/返回 JSON 解析失败：会跳过该图片，不移动文件。

## 配置保存

页面底部的“配置”支持保存/删除预设，保存位置为程序基目录下的 `Configs/`（每个配置一个 `.json` 文件）。

## 注意事项

- 该功能会移动文件（不可逆），建议先备份。
- “Model”下拉框用于检测 LM Studio 是否正常返回“已加载模型列表”；当前代码不会把所选模型名写入请求参数，实际使用的是 LM Studio 当前对话默认模型。
