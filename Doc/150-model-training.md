# 模型训练

`模型训练`页面主要用于生成 `lora-scripts` 项目的 TOML 配置，并可一键启动 PowerShell 脚本开始训练。它本身不包含训练实现，训练过程由 `lora-scripts` 负责。

## 使用前准备

- 准备好可运行的 `lora-scripts` 环境（Python、依赖、模型等），并能在命令行中正常启动训练。
- 本项目仓库中已包含 `lora-scripts/`，默认会尝试自动定位该目录。

## 快速上手

1. 设置 `lora-scripts 目录`（根目录）。
2. 设置 `TOML 输出路径`（默认会指向 `config/default.toml`）。
3. 设置 `训练脚本路径`（默认 `train_by_toml.ps1`）。
4. 在各参数分组中修改训练参数。
5. 选择：
   - “仅生成 TOML”：只写出配置文件
   - “生成并开始训练”：写出 TOML 后启动新的 PowerShell 窗口运行脚本

## 运行方式说明

点击“生成并开始训练”后会：

- 先写出 TOML 文件（UTF-8 编码）
- 再启动 `powershell.exe` 并在 `lora-scripts 目录`作为工作目录执行脚本
- 若检测到 `./venv/Scripts/Activate.ps1`，会先激活虚拟环境再执行脚本
- 若勾选“开始训练后关闭本软件”，则在启动终端后自动退出 CyanTools

## 参数编辑说明

- 页面会按分组（Section）展示参数，每个参数包含说明文本。
- 参数类型：
  - 布尔：输出 `true/false`
  - 数值：原样写入（空值会写为 `0`）
  - 字符串：会写为 TOML 字符串并转义
  - Raw：原样写入（用于数组、对象等 TOML 片段）

## 注意事项

- 本页面不会校验训练参数的正确性（例如路径是否存在、参数组合是否合理），请以 `lora-scripts` 的文档与报错为准。
- “附加参数”会直接追加到训练脚本命令后，请自行保证参数格式正确。
