# 手指完整性筛选

`手指完整性筛选` 用于在训练集整理时检测“手指崩坏”图片。当图片中检测到手部时，会基于手指关键点进行完整性判断；若任意一只手判定为缺失/畸形，则整张图片会被归为坏图并移出（或复制到指定目录）。

## 使用前准备

首次使用会自动下载两类 ONNX 模型到程序目录（需联网）。如有离线需求，也可以提前放置模型文件到默认目录：

- 手部检测模型（YOLO 格式，可选）：`Models/hand_detection/hand_detect_v1.0_s.onnx` 或 `Models/hand_detection/hand_detect_v1.0_n.onnx`
- 手指关键点模型（21 点）：`Models/hand_landmark/handpose_estimation_mediapipe_2023feb.onnx`

> 建议手指关键点模型使用 MediaPipe Hands 导出的 ONNX（21 个关键点）。若模型输入格式或尺寸不同，请在界面中调整。

下拉框可选模型与默认下载源（需要可用的网络）：
- 手部检测模型（精度优先）：`https://huggingface.co/deepghs/anime_hand_detection/resolve/main/hand_detect_v1.0_s/model.onnx`
- 手部检测模型（速度优先）：`https://huggingface.co/deepghs/anime_hand_detection/resolve/main/hand_detect_v1.0_n/model.onnx`
- 手指关键点模型：`https://huggingface.co/opencv/handpose_estimation_mediapipe/resolve/main/handpose_estimation_mediapipe_2023feb.onnx`

## 快速上手

1. 选择输入目录、坏图输出目录与好图输出目录（留空则不输出好图）。
2. 从下拉框选择手部检测模型与手指关键点模型。
3. 按需调整阈值（默认值适合多数场景）。
4. 点击“开始筛选”。

## 输出与规则

- **有手**且**任意一只手判定为崩坏**：整张图片归为坏图。
- **未检测到手**：默认视为正常（若设置好图输出目录则归为好图）。
- 输出方式（好图/坏图共用）：
  - `移动`：将好图/坏图分别移到对应目录，原目录不再保留原图。
  - `复制`：在好图/坏图目录中生成副本，原图保留。
- 若勾选“同时处理同名 txt”，会同步移动/复制同名标签文件。

## 主要参数说明

- `好图输出目录`：设置后会输出好图；留空则只处理坏图。
- `检测输入尺寸`：手部检测模型输入大小，YOLO 常用 640。
- `置信度/IOU`：手部检测阈值与 NMS IoU。
- `手类ID`：检测模型中“手”的类别索引；只有一类时用 `0`，不确定可填 `-1` 表示不过滤类别。
- `关键点输入尺寸`：手指关键点模型输入大小（MediaPipe 常用 224）。
- `输入格式`：关键点模型输入格式（`NHWC`/`NCHW`）。
- `手存在阈值`：若模型输出存在置信度，会按此阈值过滤。
- `裁剪缩放`：在检测框基础上放大裁剪，避免手部被裁太紧。
- `最小指长比例`：指尖到 MCP 的最小长度占手掌尺度的比例。
- `指尖伸展比`：指尖到手腕距离需要大于 MCP 到手腕距离的比例。
- `关键点缺失视为坏图`：关键点推理失败时是否直接判坏。

## 注意事项

- 该工具为**启发式**判断：握拳/遮挡/极端姿态可能被误判为崩坏。
- 若误判较多，可适当降低 `最小指长比例` 与 `指尖伸展比`，或提高检测阈值。
- 模型下载失败会直接报错并停止处理。
