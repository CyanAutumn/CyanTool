# 导出视频帧

`导出视频帧`用于从视频中预览并导出帧图片，支持导出当前帧、按间隔导出所有帧，以及导出 GIF。

## 快速上手

1. 点击“选择视频”选择 `mp4/avi/mov/mkv` 等视频文件。
2. 点击“选择输出目录”选择导出位置。
3. 通过滑条或“上一帧/下一帧”定位画面。
4. 选择导出方式：
   - “输出当前帧”：导出当前帧为 PNG
   - “输出所有帧”：按间隔批量导出 PNG
   - “导出为GIF”：按间隔把帧合成为 GIF

## 帧间隔（毫秒）

页面的“帧间隔 (毫秒)”会按视频 FPS 换算为跳过的帧数：

- 间隔秒数 = `毫秒 / 1000`
- 跳帧数 = `round(间隔秒数 * FPS)`，最少为 1

因此输入 `500` 表示大约每 0.5 秒导出一帧（精度取决于视频 FPS 与四舍五入）。

## 输出规则

- PNG 输出文件名：`frame_00000.png`、`frame_00010.png` ...
- GIF 输出文件名：`<视频文件名>.gif`

## 注意事项

- 导出所有帧与 GIF 可能产生大量文件/较大体积，请确保磁盘空间充足。
- GIF 的帧间隔/播放速度由编码器默认行为决定，若需要更精确控制可考虑后续用专用工具二次处理。
