# CyanTools 文档

CyanTools 是一个基于 WPF（`.NET 8 / net8.0-windows`）的桌面工具箱，面向 AI 绘图/训练相关流程：数据集整理、分辨率分桶、聚类、打标、训练配置生成、下载器、图像生成等。

## 使用前须知（重要）

- 部分工具会**删除/移动/重命名**文件（例如：`分辨率筛选`、`保留指定文件`、`图片重命名`、`训练集配平` 等）。建议先备份再操作。
- 部分工具需要网络或本地服务：
  - `图片打标` 首次使用会下载模型与标签映射文件到 `TaggerModels/`。
  - `Gemini图像生成` 需要可用的 Gemini API Key 与网络访问。
  - `LLM分类` 依赖本机 `LM Studio` 的本地 API（默认地址通常为 `http://127.0.0.1:1234`）。
  - `Danbooru下载器` / `Kemono下载器` 需要联网，并请遵守站点规则与频率限制。
- 程序的“基目录”通常是可执行文件（`.exe`）所在目录。许多输出/缓存文件会写到该目录下，例如：
  - 工作流：`Configs/Workflow/`
  - 打标模型缓存：`TaggerModels/`
  - 通用输出：`output/`
  - Gemini 配置：`config/GeminiPic/`

## 下载器解锁

`Danbooru下载器` 与 `Kemono下载器` 默认不在菜单中显示，需要在主页对隐藏图片连续点击 5 次解锁。该解锁状态为**当前进程内有效**，重启后会恢复未解锁。
