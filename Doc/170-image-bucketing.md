# 图片分辨率归类

`图片分辨率归类`会根据图片宽高比与一组候选分辨率桶（Bucket），把图片复制到输出目录下的不同分辨率子文件夹中（例如 `512x768/`）。

## 快速上手

1. 选择“输入文件夹”（只读取该目录顶层图片）。
2. 选择“输出文件夹”（会自动创建）。
3. 设置参数后点击“开始分类”。

## 参数说明

- 分辨率步长：生成候选分辨率的步长（代码中称 `divisible`），范围 8~128，常用 64。
- 最大宽高比误差：图片宽高比与最近桶宽高比的最大允许差值；超过会被跳过。
- 最大尺寸限制：候选分辨率的宽或高不会超过该值。
- 启用调试输出：输出更详细的计算/复制日志。

## 输出规则

- 输出目录结构：`<输出文件夹>/<宽>x<高>/<原文件名>`
- 行为：复制图片到输出目录，不会删除输入文件。
- 支持格式：`.jpg` / `.jpeg` / `.png` / `.bmp` / `.gif`

## 注意事项

- 该工具只复制图片文件，不会同步复制同名 `.txt`。
- 如果输入目录图片数量很大，首次读取分辨率会耗时，建议观察进度条与日志。
