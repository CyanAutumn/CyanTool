# 图片打标

`图片打标`用于对一个目录内的图片进行自动打标，生成同名 `.txt` 文件（逗号分隔 tags）。支持多种 wd14 / deepghs / cl_tagger 等 ONNX 模型，并提供阈值与标签类别过滤。

## 使用前准备

- 首次使用会从模型配置中的 URL 下载：
  - 模型文件（`.onnx`）
  - 标签映射（`.csv` 或 `.json`）
- 下载后的缓存目录：`TaggerModels/`（位于程序基目录）

若你在离线环境中使用，可手动把对应文件放入该目录，并保持与模型显示名一致的文件名。

## 快速上手

1. 选择“输入目录”（只处理该目录顶层图片）。
2. 选择“打标模型”。
3. 设置阈值与需要包含的标签类别。
4. 点击“开始打标”。

## 参数说明

- 自定义标签：始终写在最前面（去重后），用于强制加入固定 tag。
- 前置标签：如果模型预测结果中包含这些 tag，会按你填写的顺序把它们挪到输出最前面（不会强制加入不存在的 tag）。
- 通用阈值（GeneralThreshold）：
  - 用于 `通用标签 / 元信息标签`
  - 也用于“模型标签”的候选阈值
- 角色阈值（CharacterThreshold）：
  - 用于 `角色标签 / 作者标签 / 版权标签`
- 评级/质量标签：
  - 若启用，会在对应类别里取置信度最高的 1 个 tag

## 输出规则

- 支持图片格式：`.jpg` / `.jpeg` / `.png` / `.bmp`
- 对每张图片生成：`<同名>.txt`
  - 内容为 `tag1, tag2, tag3 ...`
  - 若已存在同名 `.txt` 会被覆盖

## 注意事项

- 下载模型需要网络；日志中会持续更新下载进度行。
- 模型推理默认使用 CPU（ONNX Runtime），大量图片处理时可能耗时较长。
