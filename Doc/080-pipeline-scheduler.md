# 管道调度

`管道调度`用于把多个“节点”按顺序组合为一个工作流，集中在同一处编辑各节点参数，并在右侧日志区统一查看运行日志与执行状态。

## 功能概览

- 从“可用节点”列表添加节点到“管道”列表，并支持上移/下移/移除。
- 选中管道中的节点后，右侧显示该节点的编辑界面（与对应功能页基本一致）。
- 支持工作流保存/删除/加载：
  - 保存路径：`Configs/Workflow/<工作流名>.json`
  - 通过顶部“工作流”下拉框选择已有工作流，或输入新名称后点击“保存”

## 重要限制（当前实现）

目前只有 `图片聚类` 节点支持在“管道调度”里直接执行，点击“开始”时会实际进行聚类处理。

其余节点在管道执行时只会在日志中提示“暂未接入管道执行逻辑”，不会真正处理文件。这意味着：

- 你依然可以在这里**编辑与保存**这些节点的参数（用于后续补全管道能力，或作为参数预设）。
- 需要实际运行这些工具时，请进入对应的独立页面手动执行。

## 快速上手

1. 打开 `管道调度`。
2. 左侧选择一个节点（例如 `图片聚类`），点击“添加节点”。
3. 在中间“管道”中选中该节点，右侧“节点编辑”区域设置输入/输出路径与参数。
4. 点击“开始”运行；若支持取消，则点击“取消”终止。
5. 在顶部“工作流”输入名称并点击“保存”，以便下次直接加载。

## 常见问题

### 为什么开始后没有任何处理结果？

请检查你使用的节点是否已接入管道执行逻辑。当前仅 `图片聚类` 会实际执行，其它节点会打印“暂未接入管道执行逻辑”后直接结束。

### 工作流保存在哪里？能手动编辑吗？

工作流位于 `Configs/Workflow/`。文件内容为 JSON，包含节点类型与参数快照；理论上可以手动编辑，但字段名与类型不匹配可能导致加载失败或参数不生效。
