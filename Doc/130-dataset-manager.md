# 数据集管理器

`数据集管理器`用于在同一界面完成：数据浏览、Prompt（`.txt`）编辑、分类移动/删除，以及对图片打“黑框遮挡”（并在保存时写回图片）。

## 核心能力

- 选择文件夹后，将同目录下的图片与同名 `.txt` 组合为数据项进行管理。
- 右侧设置 1~5 个分类目录，并对当前数据项标记“操作”（1~5 或 “删”）。
- 统一点击“保存所有更改”后批量执行移动/删除。
- 中间画布支持绘制黑框：保存/移动时会把黑框直接画到图片上，并在 `.txt` 中追加 `black box`。

## 快速上手（分类与 Prompt）

1. 点击“选择文件夹”，选中包含图片与 `.txt` 的目录。
2. 在右侧“分类目录”中为 1~5 设置目标文件夹路径（不存在或未设置会导致保存时报错）。
3. 在右侧“内容”中编辑当前项的 `.txt`（Prompt），按需点击 `Z(保存Prompt)` 保存。
4. 使用右侧按钮或键盘快捷键为当前项设置操作：
   - `1`~`5`：标记为对应分类
   - `D`：标记删除（操作栏显示 `删`）
   - `A`：撤销当前项操作
5. 完成标记后，点击左侧底部“保存所有更改”执行文件移动/删除。

## 快捷键（与右侧按钮一致）

- `1`~`5`：设置分类 1~5
- `Q`：随机跳转一条并复制 Prompt 到剪贴板
- `W`：上一条
- `E`：下一条并复制 Prompt 到剪贴板
- `S`：下一条
- `A`：撤销操作
- `D`：标记删除
- `Z`：保存 Prompt

当焦点位于可编辑文本框（例如内容编辑框）时，快捷键不会生效，避免误触。

## 黑框遮挡（绘制/删除）

- 左键拖拽：在图片上绘制一个矩形遮挡区域
- 左键点击已有遮挡矩形：删除该遮挡
- 右键拖拽：平移查看（当图片大于容器时）

遮挡记录会在切换图片时缓存；点击“保存所有更改”才会真正写入到输出文件。

## 保存时的文件行为（重要）

点击“保存所有更改”后，会按每条数据项的“操作”执行：

- 操作为 `删`：删除图片与 `.txt`（若 `.txt` 不是显式记录路径，也会尝试删除同名 `.txt`）。
- 操作为 `1`~`5`：移动到对应分类目录。
  - 若对该图片绘制过遮挡矩形：
    - 会把黑框直接绘制到图片上，并以 PNG 重新保存到目标目录
    - `.txt` 会在原内容基础上追加 `black box`（避免重复添加）
    - 原始图片与 `.txt` 会在源目录被删除
  - 若没有遮挡：
    - 直接移动原图与 `.txt`

以上操作会直接修改你的文件系统，建议先备份再操作。
