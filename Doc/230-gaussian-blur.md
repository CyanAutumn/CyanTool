# 高斯模糊

`高斯模糊`用于对一个文件夹内的图片批量应用高斯模糊，并输出到指定目录（不递归子目录）。

## 快速上手

1. 选择“输入文件夹”与“输出文件夹”。
2. 调整“模糊半径”（1~100）。
3. 点击“开始处理”。

## 处理规则

- 支持格式：`.png` / `.jpg` / `.jpeg` / `.bmp`
- 遍历范围：仅处理输入目录顶层文件。
- 输出文件名：保持原文件名不变，写入到输出目录。
- 模糊半径会自动调整为奇数（OpenCV 的高斯核要求）。

## 注意事项

- 输出目录不存在时会自动创建。
- 模糊后图片会失去细节，请先在少量样本上测试合适的半径再批量处理。
