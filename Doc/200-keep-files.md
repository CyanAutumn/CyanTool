# 保留指定文件

`保留指定文件`用于在指定文件夹内仅保留勾选的扩展名，其余文件将被删除（不递归子目录）。

## 快速上手

1. 点击“选择...”选择目标文件夹。
2. 在“保留的文件类型”中勾选要保留的扩展名。
3. 点击“删除其他文件”。

## 处理规则

- 遍历范围：仅处理所选文件夹顶层（不会进入子文件夹）。
- 默认可选保留扩展名：`.jpg` / `.png` / `.webp` / `.bmp` / `.jpeg` / `.npz` / `.txt`
- 未勾选的其它扩展名会被直接删除。

## 注意事项

- 删除操作不可逆，建议先备份。
- 若你在训练集目录中混有缓存文件、临时文件，此工具可用于快速清理。
