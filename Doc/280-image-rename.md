# 图片重命名

`图片重命名`用于对一个文件夹内的图片进行批量重命名，提供两种模式：按序号重命名、随机打乱重命名（GUID）。

## 快速上手（按序号）

1. 选择“输入路径”（只处理顶层文件）。
2. 设置“名称前缀 / 起始编号 / 编号位数”。
3. 点击“生成预览”，确认无冲突。
4. 点击“开始重命名”。

### 冲突判定

预览会检查：

- 生成的新文件名是否重复
- 目标文件名在目录中是否已存在

存在冲突时会提示并阻止执行。

## 快速上手（打乱）

点击“开始打乱”会把每张图片改名为随机 GUID，并尽可能避免与现有文件冲突。

### `.txt` 同步

- 打乱模式会同时重命名同名 `.txt`（如果存在），保持图片与标注文件的 base name 对齐。
- 按序号模式当前只重命名图片文件，不会同步重命名同名 `.txt`；如果你的数据集依赖 caption 文件，请谨慎使用或优先选择“打乱”模式。

## 支持格式

- `.jpg` / `.jpeg` / `.png` / `.bmp` / `.tif` / `.tiff` / `.webp`

## 注意事项

- 重命名会直接修改文件系统，建议先备份。
- 工具会通过“临时文件名中转”方式避免重命名过程中文件名碰撞。
