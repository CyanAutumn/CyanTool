# 图片处理

`图片处理`当前提供“镜像图片（左右翻转）”功能，用于批量生成镜像数据增强样本，并可同步复制同名 `.txt` 标注文件。

## 快速上手

1. 选择“目标文件夹”（只处理该目录顶层文件）。
2. 勾选“镜像图片（左右翻转）”。
3. 点击“开始处理”。

## 处理规则

- 支持格式：`.jpg` / `.jpeg` / `.png` / `.webp` / `.bmp`
- 输出位置：仍在原目录内生成新文件
- 命名规则：`原文件名_mirror.<ext>`
  - 已以 `_mirror` 结尾的文件会被跳过，避免重复镜像
- 标注文件同步：
  - 若存在同名 `.txt`（例如训练 caption），会复制为 `原文件名_mirror.txt`

## 注意事项

- 该功能会在原目录新增文件，请确保磁盘空间充足。
- 目前页面只实现了镜像处理，其它处理项预留待扩展。
