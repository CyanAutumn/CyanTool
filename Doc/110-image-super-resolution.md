# 图片超分

`图片超分`提供两套放大方案：`Real-ESRGAN` 与 `waifu2x`。输入为图片文件夹，输出为放大后的图片文件夹，并在日志区展示工具执行过程。

## 使用前准备

- 程序运行目录需要包含：
  - `realesrgan-ncnn-vulkan-20220424-windows/realesrgan-ncnn-vulkan.exe`
  - `waifu2x-caffe/waifu2x-caffe-cui.exe`
- 若缺失可执行文件，工具会直接报错提示对应路径。

## Real-ESRGAN

### 操作步骤

1. 选择“输入目录”（包含待处理图片）。
2. 选择“输出目录”（可留空，留空时使用默认输出目录）。
3. “选择工具”选 `Real-ESRGAN`。
4. 选择模型、放大倍数、GPU、瓦片大小。
5. 点击“开始超分”。

### 参数说明

- 模型：来自 `realesrgan-ncnn-vulkan-20220424-windows/models/*.param`（下拉框自动读取）。
- 放大倍数：2 / 3 / 4。
- 选择 GPU：`GPU 0` / `GPU 1`（对应 `-g` 参数）。
- 瓦片大小：对应 `-t` 参数；`0` 表示不分块（由工具自身解释）。
- 输出目录留空时：默认输出到 `<输入目录>/output`。

## waifu2x

### 操作步骤

1. “选择工具”选 `waifu2x`。
2. 设置放大倍数、降噪等级、是否使用照片模型、裁剪大小。
3. 点击“开始超分”。

### 参数说明

- 放大倍数：以浮点形式传给工具（例如 `2.0`）。
- 降噪等级：0~3；大于 0 时使用 `noise_scale` 模式，否则使用 `scale` 模式。
- 使用照片模型：开启后传递 `-p photo`。
- 裁剪大小：大于 0 时传递 `-c <cropSize>`。
- 输出目录留空时：默认输出到 `<输入目录>/output_waifu2x`。

## 输出与注意事项

- 输出为图片文件（不会修改输入目录原图）。
- 若勾选“完成后打开目录”，成功结束后会自动用资源管理器打开输出目录。
- 日志里会显示执行命令与工具输出；可用于排查模型/路径/参数问题。
