# 格式转换

`格式转换`用于把一个目录内的图片批量转换为指定格式，并输出到新目录（不递归子目录）。

## 快速上手

1. 选择“输入路径”与“输出路径”。
2. 选择“目标格式”（PNG/JPEG/BMP/WEBP）。
3. 点击“开始转换”，等待进度条完成。

## 处理规则

- 支持输入格式：`.png` / `.jpg` / `.jpeg` / `.bmp` / `.webp` / `.psd`
- 遍历范围：仅处理输入目录顶层文件。
- 输出命名：保持原始文件名的 base name，扩展名改为目标格式的小写（例如 `a.png` → `a.webp`）。
- `.txt` 同步：
  - 当输入目录与输出目录不同且存在同名 `.txt` 时，会复制到输出目录（会覆盖同名文件）。

## 注意事项

- 该工具不会删除输入原图，只在输出目录生成新文件。
- 若你希望保留原有文件名与标注文件一致，建议保持输入图片与 `.txt` 的 base name 对齐再转换。
