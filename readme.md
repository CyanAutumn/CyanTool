# Danbooru 图像爬虫

本工具是一个 Windows 窗体应用程序，用于从 `danbooru.donmai.us` 网站下载图片及其对应的标签。

## 功能

1.  **按标签批量下载:**
    *   用户可以指定一个或多个标签进行搜索。
    *   应用程序会逐页爬取所有匹配标签的帖子。
    *   对于每个帖子，它会下载高分辨率图片 (`large_file_url`)。
    *   它会将图片的标签保存到一个与图片文件同名的 `.txt` 文件中。标签以逗号分隔的形式保存。

2.  **按帖子 ID 下载:**
    *   用户可以通过提供特定的帖子 ID 来下载单个图片及其标签。

3.  **基于 Cookie 的身份验证:**
    *   应用程序需要在界面中输入用户提供的 Cookie。这些 Cookie 用于所有下载请求，这对于访问某些内容或遵守网站的 API 使用政策可能是必需的。
    *   关闭应用程序时，Cookie 会自动保存到 `cookies.txt` 文件中，并在启动时重新加载。

## 如何使用

1.  **Cookies:** 将您的 `danbooru.donmai.us` Cookie 粘贴到“Cookies”文本框中。
2.  **批量下载:**
    *   在“Tag”文本框中输入您要下载的标签。
    *   点击“Start”按钮。
    *   应用程序将开始将图片和标签文件下载到应用程序目录下的 `output` 文件夹中。
    *   点击“Stop”停止该过程。
3.  **单个下载:**
    *   在“Download by ID”按钮旁边的文本框中输入帖子 ID。
    *   点击“Download by ID”按钮。

## 输出

*   **图片:** 保存在 `output` 文件夹中。
*   **标签:** 作为 `.txt` 文件保存在 `output` 文件夹中，每个文件对应一张图片。

## 数据集管理器

一个用于整理和清理图片数据集的工具。

### 功能

- **文件夹选择:** 选择包含您图片的文件夹。
- **图片预览:** 逐个查看图片。视图支持平移（鼠标右键）和缩放（鼠标滚轮）。
- **分类:** 将图片分配到五个类别之一。每个类别对应一个您可以指定的目标文件夹。使用数字键 (1-5) 快速分配类别。
- **文件操作:**
  - **下一张/上一张:** 使用“S”/“W”键或相应按钮浏览图片。
  - **删除:** 按“D”键将图片标记为删除。
  - **撤销:** 按“A”键撤销上一个操作（分类或删除）。
- **保存:** 所有操作（移动和删除）都是暂存的。点击“保存所有更改”以将它们应用到文件系统。

## 如何使用

1.  点击“选择文件夹”加载图片。
2.  在右侧面板中为您的类别定义目标文件夹。
3.  使用键盘快捷键或按钮来导航和整理您的图片。
4.  点击“保存所有更改”以执行所有暂存的操作。

## 导出视频帧

一个从视频文件中提取帧的工具。

### 功能

- **视频和输出选择:** 选择一个视频文件和用于保存导出帧的目标文件夹。
- **帧预览:** 查看视频中的当前帧。
- **导航:**
  - 使用滑块在视频时间线上拖动。
  - 使用“上一帧”和“下一帧”按钮进行精确导航。
  - 设置帧间隔（以毫秒为单位）以控制上一帧/下一帧按钮的步长。
- **导出:**
  - **输出当前帧:** 将当前显示的帧另存为图片。
  - **输出所有帧:** 从视频中提取每一帧并将其另存为图片。

### 如何使用

1.  选择一个视频和输出路径。
2.  导航到所需的帧或决定导出所有帧。
3.  点击相应的导出按钮。

## 图像分辨率分桶

该工具根据图像的分辨率和宽高比自动将其分类到文件夹中，这对于准备用于模型训练的数据集非常有用。

### 功能

- **自动分类:** 从输入文件夹中读取图像，并将其移动到以其分辨率分桶命名的子文件夹中（例如 `512x768`）。
- **可配置参数:**
  - **分辨率步长:** 创建分辨率分桶的步长。通常为 64。
  - **最大宽高比误差:** 图像的宽高比可以与分桶的宽高比相差多少。
  - **最大尺寸限制:** 生成的分辨率分桶的上限。
- **日志记录:** 显示其操作的详细日志。

### 如何使用

1.  选择输入和输出文件夹。
2.  根据需要调整参数。
3.  点击“开始分类”。

## 图像超分辨率 (Real-ESRGAN & waifu2x)

2.  选择所需的放大工具（`Real-ESRGAN` 或 `waifu2x`）。
3.  配置特定于工具的选项（模型、比例等）。
4.  点击“开始超分”。

## 三段式裁剪

一种高级工具，使用一系列对象检测模型自动将动漫风格的图像裁剪为全身、半身、头部和眼睛的特写。

### 功能

- **多阶段检测:** 依次运行人物、半身、头部和眼睛检测模型，以生成各种裁剪图像。
- **微调:** 调整每个检测阶段（人物、头部、眼睛）的置信度阈值和比例，以控制裁剪行为。
- **标签管理:** 可选择为裁剪后的图像保留原始标签。

### 如何使用

1.  选择输入和输出文件夹。
2.  根据需要启用或禁用人物和眼睛检测阶段。
3.  为每个检测模型调整置信度和比例参数。
4.  点击“开始处理”。

## LLM 文件分类器

一个与大型语言模型 (LLM) 交互以执行文件分类任务的界面。

### 功能

- **模型交互:** 选择一个正在运行的 LLM，提供主输入（指令）和工作目录。
- **路径映射:** 定义最多五个编号的路径，LLM 可以将其用作文件操作的目标。
- **执行:** 该工具将指令和路径映射发送到 LLM，然后 LLM 根据提示执行文件操作（如移动文件）。
- **配置管理:** 保存和加载不同的路径和设置集。

### 如何使用

1.  确保您的 LLM API 正在运行。
2.  从下拉列表中选择模型。
3.  在“主输入”框中编写清晰的指令（例如，“将所有猫的图片分类到路径 1，将所有狗的图片分类到路径 2”）。
4.  设置“工作文件夹”并定义目标路径 (1-5)。
5.  点击“运行”将命令发送到 LLM。
